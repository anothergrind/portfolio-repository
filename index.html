Geomagnetic Storm Predictor

Forecasting Space Weather · 3-Hour Prediction

Geomagnetic storms can disrupt satellites, GPS, aviation systems, and power infrastructure. This project builds three machine learning classifiers to predict whether a geomagnetic storm will occur in the next 3 hours from OMNI solar-wind parameters, solar-flare activity, and CME data. We trained and deployed XGBoost, LSTM, and TCN models on 30 years of observations, evaluated with chronological splits to avoid time leakage, and shipped them behind an interactive Streamlit dashboard for side-by-side comparison and real-time forecasting.

Overview

🌪️

The Challenge: Geomagnetic storms are rare but high-impact events. A naive model can achieve great accuracy scores while catching almost nothing. We needed to predict whether the Ap index (a measure of geomagnetic disturbance) will reach storm thresholds in the next 3 hours — balancing sensitivity to true storms against the cost of false alarms.

Our Solution: We built a time-binned dataset from OMNI solar-wind parameters, NASA DONKI CME events, solar-flare counts, and geomagnetic indices, spanning 1995–2024. We trained three different model architectures — XGBoost for interpretability, LSTM for sequential dependencies, and TCN for causal temporal convolution — all with chronological train/test splits to prevent time leakage. Each model uses different strategies to handle severe class imbalance: oversampling, pos-weighted loss, and focal loss. The final models are deployed behind an interactive Streamlit dashboard.

Models

All three classifiers predict whether the Ap index will reach 50 (roughly Kp 5 storm conditions) in the next 3 hours. Each is trained on 2010–2021 and evaluated on the same held-out 2022–2024 test period. The models trade off different strengths: XGBoost offers interpretability and high recall; LSTM achieves the highest precision and PR-AUC; TCN delivers the best overall F1 balance.

Storm Predictor — XGBoost

A gradient-boosted tree classifier that forecasts storm risk 3 hours ahead from 45 engineered features of the current 3-hour bin — solar wind, magnetic field, flare counts, CME activity, and 27-day recurrence — with no current Ap features. Highest recall of the three, and the most interpretable baseline.

DatasetSingle 3-hour bins, 2010–2024 (OMNI + DONKI + flares)
ModelXGBoost + RandomOverSampler, threshold 0.90
ResultPR-AUC 0.575 · Recall 0.684 · F1 0.485

Storm Predictor — LSTM

A 2×128 recurrent sequence model trained with pos-weighted BCE that reads a rolling 48-hour window of 8 solar-wind and Ap channels instead of a single bin. Best precision and PR-AUC of the three — when it calls a storm, it's usually right.

Dataset48-hour sequences (16 bins × 8 channels), 2010–2024
ModelLSTM 2×128, pos-weighted BCE, threshold 0.795
ResultPR-AUC 0.610 · Precision 0.729 · F1 0.555

Storm Predictor — TCN

A causal dilated convolutional network trained with focal loss on a rolling 48-hour solar-wind history, without ever seeing the current Ap index. Architecture and imbalance strategy were both chosen on a chronological validation split, then refit once on the full training window. Best overall F1 — the most balanced of the three.

Dataset48-hour solar-wind sequences, no current Ap, 2010–2024
ModelTCN 4×64, focal loss (α .75, γ 2), threshold 0.60
ResultF1 0.580 · PR-AUC 0.602 · ROC-AUC 0.956

Timeline

Aug 2026

Deployment — Streamlit Dashboard

Shipped three final model artifacts and cached test-period predictions behind an interactive Streamlit multi-page dashboard. Features include adjustable decision thresholds, confusion matrices, precision-recall curves, dataset statistics, model performance comparison, and a forecast explorer for individual storm events with solar-wind, flare, and CME conditions.

Jul 2026

Sequence Modeling — LSTM & TCN

Scaled up from single-bin tabular models to 48-hour rolling window sequences. Trained an LSTM (2×128) with pos-weighted BCE and a causal dilated TCN (4×64) with focal loss. Tuned operating thresholds to maximize F1 while managing the imbalanced positive class on held-out data.

Jun – Jul 2026

Data Pipeline & Baseline Classifiers

Ingested OMNI solar-wind, NASA DONKI CME, solar-flare, and geomagnetic indices. Built 87,649-row dataset binned into 3-hour windows (1995–2024). Ran per-source EDA. Built baseline classifiers: logistic regression, decision tree, random forest, SVM, and XGBoost using RandomOverSampler to address class imbalance.
