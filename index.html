Geomagnetic Storm Predictor

Forecasting geomagnetic storms with machine learning

We forecast whether a geomagnetic storm will occur in the next 3 hours using solar-wind, solar-flare, CME, and geomagnetic-history data. Three classifiers — XGBoost, LSTM, and TCN — are trained on a 1995–2024 time-binned dataset and compared side-by-side in an interactive Streamlit dashboard.

About

GSP

Geomagnetic storms can disrupt satellites, GPS, radio communication, aviation systems, and power infrastructure. Strong storms are rare but high-impact, so prediction systems need to catch true storms while keeping false alarms low. This project was developed as part of AI4ALL Ignite to ask: can solar-wind, flare, CME, and geomagnetic history data predict whether a storm will occur in the next 3 hours?

We built a time-binned modeling dataset from 1995–2024 space-weather observations, trained baseline models (logistic regression, random forest, decision tree, SVM) and three final time-aware classifiers (XGBoost, LSTM, TCN) using chronological train/test splits to avoid time leakage, and deployed all three behind an interactive Streamlit dashboard. This project was built by a six-person team: Nithila Sadheesh, Kamsi Ozorji, Nancy Nakyung Kwak, Chan Li, Hafsah Khan, and Nana Oppong Ampofo.

Storm Predictor — XGBoost

A tree-based classifier that forecasts geomagnetic storm risk 3 hours ahead using engineered tabular features from the current 3-hour space-weather bin (no current Ap features).

Datasettime_binned_dataset.csv, 1995–2024, 3-hr bins
ModelXGBoost, chronological split (train 2010–2021, test 2022–2024)
ResultPR-AUC 0.575 · Precision 0.375 · Recall 0.684 · F1 0.485

Storm Predictor — LSTM

A recurrent sequence model that scores storm risk from a rolling 48-hour history of solar-wind and Ap features. Highest precision and PR-AUC of the three deployed models.

Storm Predictor — TCN

A causal dilated convolutional network that scores storm risk from a rolling 48-hour solar-wind history, without current Ap features. Achieved the strongest final F1 score of the three deployed models.

Dataset48-hour solar-wind sequences from time_binned_dataset.csv
ModelTCN, chronological split (train 2010–2021, test 2022–2024)
